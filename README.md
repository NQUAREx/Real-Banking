# Real Bank

Мобильный фронтенд по предоставленным референсам. React + Vite. Темные счета и карты, выбор основной карты, нижнее меню, QR-сканер, галерея, свой QR и перевод с проверкой суммы, подтверждением и анимацией результата.

## Локально

```sh
npm ci
npm run dev
npm test
npm run build
npm run preview
```

## GitHub Pages

В Settings → Pages выберите Source: GitHub Actions. Workflow `.github/workflows/pages.yml` собирает и публикует ветку main. Все пути относительные, включая manifest и service worker: поддерживаются `/Real-Banking/` и корень своего сервера. Для своего сервера загрузите содержимое dist через HTTPS.

## Установка

- iOS Safari: Поделиться → На экран «Домой» → открыть установленную иконку. Используется standalone с учетом safe area.
- Android Chrome: меню → Установить приложение. Manifest запрашивает fullscreen; доступность зависит от браузера.
- Камера требует HTTPS (или localhost) и разрешения пользователя. Используется задняя камера; вспышка и зум работают, если устройство предоставляет их браузеру. При отказе можно загрузить фото из галереи.

## Заглушки

Реальных платежей и серверной интеграции нет. QR печатается в консоль как `[Real Bank] QR scanned`, подтверждение — `[Real Bank] Transfer stub`. Баланс не меняется. Не используйте настоящие платежные данные при демонстрации.

Сканер читает QR через ZXing (включая Safari без BarcodeDetector). Код не открывает ссылки из QR. Поддерживается JSON `{ "recipient": "Кофейня", "account": "DEMO-123", "amount": 125 }` и URL с параметрами name/recipient/merchant, account/reference, amount. Остальные QR сохраняются как исходная строка, сумма вводится вручную. Спецификацию банковских EMV/Элкарт QR и проверку получателя необходимо подключить через сервер партнера; выбор географии сейчас лишь переключает вкладку. Штрихкоды не декодируются в этой версии, несмотря на текст из референса.

Для снятых/закрашенных в референсах реквизитов использованы демонстрационные названия. Дополнительные экраны и анимации сделаны в той же стилистике: исходные изображения не задают их поведение.

Проверка перед реальным запуском: сценарии на физических iOS/Android, соглашение с банком, серверная авторизация и валидация переводов. Секреты банка не должны попадать в клиентский код.
